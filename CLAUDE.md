# XMB для HiBy R3II

Своя оболочка (LVGL 9) вместо стокового плеера. Устройство железа и кода — `NOTES.md`,
замысел — `DESIGN.md`.

## Тикеты — обязательны

Файловый трекер: `powershell -File scripts/tickets.ps1 <команда>`. Правила и поля —
`tickets/README.md`. Контекст сессии стирается, тикеты — нет.

- Пакет просьб пользователя → по тикету на пункт, до начала работы.
- Пользователь принял решение в диалоге → `decision`-тикет в ту же сессию.
- Начал работу → `set -Status in-progress`; сделал → `fixed` + `-Commits`.
- Баг вне скоупа или отложенная работа → тикет, а не TODO в чате.
- Конец сессии, если тикеты трогались → `board` + `validate`, коммитить вместе с кодом.
- `verified` агент не ставит сам — только по словам пользователя.

## Windows-ловушки

- `scripts/tickets.ps1` обязан быть **UTF-8 с BOM**: PowerShell 5.1 иначе читает его как ANSI
  и падает на кириллице.
